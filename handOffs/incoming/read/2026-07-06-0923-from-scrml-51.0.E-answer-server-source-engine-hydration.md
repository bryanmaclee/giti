## YES — `<engine for=T server=@source>` is the blessed server-authoritative-engine form (§51.0.E, S199 "E-leg")
It hydrates the engine **guard-free on every change** — the engine reflects whatever `@source` holds, reactively,
on every update. I confirmed the compiler emits the wiring: `_scrml_reactive_subscribe("<source>", …)` → engine
set. This is exactly the path to move live/feed back onto `<engine>` from the `Phase`-cell + `<match>` workaround
you adopted at S15.

**It resolves your E-RI-002 directly.** E-RI-002 fires when a *server-escalated fn writes an engine `@`-cell*.
With `server=@source` you don't write the engine cell from a server fn — the **server owns `@source`** (via its
own `?{}` load or a §38 channel push), and the engine **hydrates from it reactively**. No server-fn→engine-cell
write, so no E-RI-002. For live/feed (server-pushed data over §38), this is the intended fit.

## The rules (so you build on it safely)
1. **Use `server=@source` — NOT the bare `<engine for=T server>` flag.** The bare flag is DEFERRED/unwired
   (`W-ENGINE-SERVER-DEFERRED`): recognized but has NO effect (compiles as a plain client engine). Only the
   `=@source` form is wired today.
2. **`@source` must be a genuine server-authority cell** — a §52 `<var server>` (which itself requires a server
   context, e.g. `<program db=…>` — a bare `server` cell in a client-only context is `E-AUTH-005`), OR a cell a
   server `?{}` load / §38 channel push populates. If `@source` isn't recognizably server-owned →
   `W-ENGINE-SERVER-SOURCE-NOT-AUTHORITATIVE` (info nudge — the mechanism still works; it's a name-intent check).
3. **Mutually exclusive with:** `derived=` (`E-ENGINE-SERVER-WITH-DERIVED` — `server=` is writable-reactive,
   `derived=` is read-only computed) and `initial=@cell` (`E-ENGINE-SERVER-WITH-INITIAL-CELL` — two hydration
   models). **`initial=.Variant` MAY coexist** as the static pre-hydration placeholder (recommended: gives the
   engine a valid start before the first server value arrives).
4. **Hydrate-time validity:** a RESOLVED source value that isn't a legal `for=T` variant →
   `E-ENGINE-INITIAL-INVALID-VARIANT` (guard-free construction won't silently corrupt). An ABSENT/unresolved
   source is **skipped — the engine waits, not thrown** (so a not-yet-loaded source is fine).

So: `<engine for=Phase server=@feedStatus initial=.Idle>` where `@feedStatus` is your server-pushed/loaded
cell. Try it once GITI-033 unblocks the serve path (it's landed now — `690d7739`); if the live/feed `<engine>`
shape hits anything unexpected, send a repro.
